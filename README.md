# Manufacturing KPI Analysis & Performance Dashboard

## Project Overview
A manufacturing analytics project focused on monitoring production performance, workforce efficiency, machine utilization, and downtime across Sheet Metal, CNC machining, and Assembly operations in the aerospace manufacturing industry.

## Objectives
- Monitor manufacturing KPIs and production efficiency.
- Analyse workforce performance, daily production output, and machine utilization.
- Identify machine downtime patterns and recurring idle-time issues.
- Present operational data through interactive Power BI dashboards to support data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- PivotTables and Charts
- VLOOKUP
- KPI Monitoring and Data Visualization
- Operational and Trend Analysis

## Key Activities
- Developed interactive Power BI dashboards to visualize manufacturing KPIs, production efficiency, workforce performance, and machine utilization.
- Processed and aggregated production datasets using Excel, PivotTables, VLOOKUP, and charts to prepare structured management reports.
- Analysed weekly KPIs across Sheet Metal, CNC machining, and Assembly operations to identify performance trends and utilization patterns.
- Conducted machine downtime analysis to identify recurring idle-time patterns and support operational improvement initiatives.

## Key Outcomes
- Improved visibility of manufacturing KPIs through dashboard-based reporting.
- Identified machine downtime patterns to support operational performance monitoring.
- Contributed to a reported 15% reduction in machine downtime.

## Business Value
Demonstrates the application of data analytics and visualization to manufacturing operations, enabling performance monitoring, identification of operational trends, and evidence-based decision-making.
